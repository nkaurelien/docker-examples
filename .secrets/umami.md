# Umami Web Analytics Credentials & Documentation

- **Service**: Umami Privacy-First Web Analytics
- **URL**: https://umami.kamitbrains.fr
- **Database Engine**: PostgreSQL 16 (`postgres:16-alpine`)
- **Admin Login File**: `.secrets/umami-admin-login`
- **Admin Password File**: `.secrets/umami-admin-password`
- **DB Password File**: `.secrets/umami-db-password`
- **App Secret File**: `.secrets/umami-app-secret`
- **Protection**: Traefik TLS + CrowdSec Bouncer + Native Umami Auth
