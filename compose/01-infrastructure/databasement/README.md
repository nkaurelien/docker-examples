# Databasement — Database Backup Manager & Web UI

Databasement is an open-source, self-hosted database backup management application with a Web UI.

## Features
- **Multi-Database Support**: MySQL, PostgreSQL, MariaDB, MSSQL, MongoDB, SQLite, Firebird, Redis/Valkey.
- **Automated Scheduling**: Scheduled backups, retention policies, and cross-server automated restores.
- **SSH Tunnels**: Connect securely to database instances behind bastions or firewalls.
- **Encrypted Storage**: gzip, zstd, and AES-256 encryption stored to S3, SFTP, SMB, or local storage.
