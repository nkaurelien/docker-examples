# Backrest — Web UI & Orchestrator for Restic

Backrest is a web-based UI and backup orchestrator built for Restic.

## Features
- **Cron Scheduling**: Built-in scheduler for backups, prunes, and checks.
- **Snapshot Browser**: Explore files inside Restic snapshots and restore directly.
- **Storage Backends**: Native support for S3, MinIO, SFTP, and Rclone remotes.
- **Hooks**: Pre- and post-backup hooks for database dumps (`pg_dump`, `mysqldump`).
