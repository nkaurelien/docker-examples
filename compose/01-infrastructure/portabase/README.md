# Portabase — Open Source Database & Volume Backup Platform

Portabase is an open-source, self-hosted platform designed for multi-database backup, restoration, and volume management.

## Features
- **Multi-Engine Support**: Supports PostgreSQL, MySQL, MariaDB, MongoDB, Redis, and SQLite.
- **Docker Volume Backup**: Automated snapshot and restoration of persistent Docker volumes.
- **Traefik Integration**: Automatic TLS certificates via Let's Encrypt and CrowdSec security.

## Quick Start

```bash
docker compose up -d
```

Access the web UI at `https://portabase.kamitbrains.fr`.
