# BentoPDF

BentoPDF is a privacy-first, client-side PDF toolkit designed to run entirely in your web browser.

## Features
- **Privacy First**: All PDF operations happen locally in your browser without uploading sensitive documents.
- **Lightweight**: Minimal CPU and RAM footprint.
- **Traefik Integration**: Out of the box reverse proxy setup with TLS & domain routing.

## Usage

```bash
docker compose up -d
```
