# Gotify — Real-Time Push Notification Server

Gotify is a self-hosted server for sending and receiving push notifications in real-time.

## Features
- **Real-Time Push Notifications**: Instant WebSocket communication.
- **REST API**: Simple HTTP API for sending messages from any client or script.
- **Client Management**: Create distinct tokens per application or script.
- **Traefik Integration**: TLS encryption with Let's Encrypt and CrowdSec security.

## Quick Start

```bash
docker compose up -d
```

Access the web UI at `https://gotify.kamitbrains.fr`.
