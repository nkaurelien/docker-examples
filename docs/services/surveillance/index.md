# Web Surveillance & Monitoring

Solutions for web page monitoring, change detection, and website surveillance.

## Available Services

| Service | Description | URL |
| :--- | :--- | :--- |
| [ChangeDetection.io](changedetection.md) | Open-source web page & API change surveillance | `https://changedetection.kamitbrains.fr` |

## Feature Overview

- **Change Detection**: Track text changes, price updates, HTML elements, JSON APIs, and PDF documents.
- **Alerting & Notifications**: Send instant push notifications via Ntfy (`https://ntfy.kamitbrains.fr`), Discord, Slack, Telegram, or Webhooks when changes occur.
- **Visual Diffs**: Inspect side-by-side visual diffs of web pages directly in the browser interface.
